# syscache

Потокобезопасный in-memory кэш на Go с единым TTL для всех записей, ограничением
ёмкости и возможностью подмены источника времени.

Пакет не требует зависимостей и рассчитан на Go 1.26+ (используются дженерики).

## Возможности

- **Дженерики**: любой comparable-тип ключа и любой тип значения.
- **TTL**: у всех записей одинаковое время жизни, задаваемое при создании кэша.
- **Ограничение ёмкости**: при переполнении вытесняется самая старая запись.
- **Ленивая очистка**: истёкшие записи удаляются при обращении к кэшу.
- **Инъекция времени**: детерминированные тесты через `WithClock`.
- **Потокобезопасность**: все операции защищены мьютексом.

## Установка

Модуль называется `syscache`, пакет — `syscache/cache`:

```bash
go get syscache/cache
```

```go
import "syscache/cache"
```

Если пакет используется внутри другого модуля локально, добавьте его в `go.mod`
через `replace` или скопируйте пакет в свой репозиторий.

## Быстрый старт

```go
package main

import (
	"fmt"
	"time"

	"syscache/cache"
)

func main() {
	c := cache.New[string, int](
		cache.WithTTL[string, int](5*time.Minute),
		cache.WithCapacity[string, int](1000),
	)

	expiresAt := c.Set("answer", 42)
	fmt.Println("истекает:", expiresAt)

	if v, ok := c.Get("answer"); ok {
		fmt.Println("значение:", v)
	}

	c.Delete("answer")
	fmt.Println("размер:", c.Len())
}
```

## API

### Создание

```go
func New[K comparable, V any](opts ...Option[K, V]) *CacheWithConstTTL[K, V]
```

По умолчанию:

| Параметр   | Значение            |
|------------|---------------------|
| TTL        | `1 час`             |
| Ёмкость    | `0` — без ограничения |
| Источник времени | `time.Now`   |

### Методы

```go
// Set сохраняет значение и возвращает момент истечения записи.
func (c *CacheWithConstTTL[K, V]) Set(key K, value V) time.Time

// Get возвращает значение и признак наличия. Для отсутствующей или истёкшей
// записи возвращает zero value и false.
func (c *CacheWithConstTTL[K, V]) Get(key K) (V, bool)

// Delete удаляет запись. Удаление отсутствующего ключа — no-op.
func (c *CacheWithConstTTL[K, V]) Delete(key K)

// Len возвращает количество живых записей, попутно удаляя истёкшие.
func (c *CacheWithConstTTL[K, V]) Len() int
```

### Опции

```go
// WithTTL задаёт время жизни всех записей. По умолчанию — 1 час.
cache.WithTTL[K, V](time.Minute)

// WithCapacity задаёт максимальное число записей.
// 0 или отрицательное значение — без ограничения.
cache.WithCapacity[K, V](10_000)

// WithClock подменяет источник времени (полезно в тестах).
// nil игнорируется, остаётся time.Now.
cache.WithClock[K, V](func() time.Time { return fixedTime })
```

Опции применяются по порядку, поэтому при повторной передаче одной и той же
опции побеждает последняя.

## Поведение

### TTL

- Время жизни отсчитывается от последнего `Set` для конкретного ключа.
- `Get` **не** продлевает TTL — это не sliding expiration.
- Запись считается истёкшей, когда `expireAt <= now` (в момент `expireAt` она
  уже недоступна).
- `TTL <= 0` означает, что запись истекает сразу после вставки.
- Очистка ленивая: истёкшие записи удаляются при вызове `Set`, `Get` или `Len`.
  Фонового сборщика нет.

### Ёмкость и вытеснение

Записи хранятся в двусвязном списке в порядке времени истечения. Так как TTL
единый, этот порядок совпадает с порядком вставки/обновления:

- при вставке новой записи сверх лимита удаляется голова списка — самая старая
  по времени истечения запись;
- `Set` для существующего ключа обновляет значение, TTL и перемещает запись в
  конец списка, поэтому она становится «самой свежей»;
- `Get` не меняет порядок вытеснения;
- обновление существующего ключа не увеличивает размер и не вызывает вытеснения.

### Потокобезопасность

Все публичные методы используют общий `sync.Mutex`, поэтому кэш безопасен для
конкурентного использования из нескольких горутин. Один экземпляр кэша
сериализует операции; для высокой нагрузки с преобладанием чтения реализация
не оптимизирована (`RWMutex` не используется). Внутренний источник времени
должен быть потокобезопасным, если он разделяется между горутинами.

### Сложность

| Операция | Сложность |
|----------|-----------|
| `Set`    | O(1) амортизированно |
| `Get`    | O(1) амортизированно |
| `Delete` | O(1) |
| `Len`    | O(1) + стоимость удаления истёкших записей |

## Ограничения

- Нет фонового удаления истёкших записей: если к кэшу долго не обращаются,
  память освобождается только при следующем вызове `Set`, `Get` или `Len`.
- Нет sliding expiration, пер-ключевого TTL, статистики попаданий и колбэка
  вытеснения.
- Интерфейс `Cacher` в `cache/cache.go` — заготовка и пока не реализован
  типом `CacheWithConstTTL`.
